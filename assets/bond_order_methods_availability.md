## Notes

- The name BondNet is also used by an unrelated bond-dissociation-energy GNN (Wen et al. 2021). Cite the bond-perception BondNet by its ChemRxiv DOI.
- BondNet's checkpoints were released on Zenodo on 2026-10-01 (10.5281/zenodo.23080342). The repository is new, so the adapter pins a commit.
- YuelBond has no licence file, so by default all rights are reserved. The adapter clones the code and downloads the weights at setup time, and bond-bench redistributes neither. Ask the authors to add a licence before publishing results that depend on it.
- cod-tools (#28) is excluded because stratum A2 keeps only COD entries whose coordinate-derived structure Merkys et al. (#29) found isomorphic with the curated SMILES. That pipeline helped choose its own test set, so its A2 score would be inflated.
- BALL (#12) and indigo-bondorder (#14) assign bond orders to a given connectivity. Their adapters receive the harness contact map (`core/geometry.contact_map`, the same one `canonical-O` uses), so connectivity errors are shared with `canonical-O` and not specific to these methods.
- I-interpret's web address comes from the 2007 paper. Whether the server is still online was not checked.
- The MiDi, HIP-NN, Open Babel, xyz2mol and HuLiS entries come from prior knowledge. Confirm the repositories before citing them in a publication.
