# Dataset licenses

The bond-bench dataset is distributed as files attached to GitHub releases and fetched with `bond-bench pull`. Every file is derived from third-party data, and each keeps the terms of the sources it was built from. This file states those terms, file by file and source by source. It covers the data only. It does not cover the bond-bench source code.

Licenses were checked against each source's own license statement on 2026-10-19. This is a summary, not legal advice. When in doubt, the license linked for each source is authoritative.

## Terms by file

| file | built from | terms |
| --- | --- | --- |
| `A1.h5` | RCSB PDB entries, wwPDB Chemical Component Dictionary, RCSB validation metrics | CC0 1.0 |
| `A2.h5` | Crystallography Open Database; Merkys et al. (2023) Additional file 2 | CC0 1.0 |
| `B1.h5` | QMugs; ChEMBL 27 | **CC BY-SA 3.0 (share-alike)** |
| `B2.h5` | GEOM-DRUGS | CC0 1.0 |
| `B3.h5` | QCML (CC BY-NC 4.0); GEOM-QM9 (CC0 1.0) | **CC BY-NC 4.0 (non-commercial)** |
| `B5.h5` | Tautobase; Dhaked–Nicklaus Tautomer Database | **no license published by either source; see below** |
| `C1.h5` | B1 with added coordinate noise | **CC BY-SA 3.0 (share-alike)** |
| `C5.h5` | QCML (CC BY-NC 4.0); Transition1x (MIT); Grambow et al. reactions (CC BY 4.0) | **CC BY-NC 4.0 (non-commercial)**, plus the MIT notice and CC BY 4.0 attribution below |
| `index.parquet` | SMILES, InChIKeys and source ids of every stratum | each row follows the terms of its `stratum_id` |
| `reports/*.json` | build statistics produced by bond-bench | no third-party content |

The terms differ by file, so the release cannot carry a single license. In practice:

- **Commercial use** is not permitted for `B3.h5` or `C5.h5`, or for anything adapted from them.
- **Share-alike** applies to `B1.h5` and `C1.h5`. If you adapt them, you must release the result under CC BY-SA 3.0 or a compatible later version, such as CC BY-SA 4.0. Keep the ChEMBL IDs (`meta_chembl_id` in `B1.h5`, and the `source_id` prefix in both files) and state that they come from ChEMBL release 27.
- **Do not merge** B1/C1 records with B3/C5 records into one adaptation. Share-alike and non-commercial terms are mutually incompatible. Keep them as separate files.
- **No upstream restrictions** apply to `A1.h5`, `A2.h5` or `B2.h5`; all of their sources are CC0. Please still cite the sources and credit the original depositors.

### `B5.h5`: redistribution permission unconfirmed

Neither tautomer source publishes a license. The Tautobase repository has no license file. The NCI CADD download page describes the Dhaked–Nicklaus database as "freely available" but grants no explicit license. The tautomer graphs and preference labels in `B5.h5` come from these sources. The 3D geometries are generated by bond-bench (RDKit ETKDG followed by GFN2-xTB relaxation). Until the authors confirm that redistribution is permitted, treat `B5.h5` as research use only, and cite both databases. Tautobase draws mainly on the Kenny–Taylor tautomer codex, which is CC BY 4.0; cite it as well.

## Sources

### RCSB PDB / wwPDB (A1)

mmCIF entries, Chemical Component Dictionary definitions, and validation metrics (RSCC, RSR) from the RCSB Data and Search APIs.

- **License:** CC0 1.0. Data from RCSB's programmatic APIs is covered by the same license. See <https://www.wwpdb.org/about/usage-policies> and <https://www.rcsb.org/pages/usage-policy>.
- **Requested:** attribution of the original authors of each structure (the PDB id is in `meta_pdb_id`).
- **Cite:**
  - Berman HM et al. The Protein Data Bank. *Nucleic Acids Res.* 28:235–242 (2000). doi:10.1093/nar/28.1.235
  - wwPDB consortium. Protein Data Bank: the single global archive for 3D macromolecular structure data. *Nucleic Acids Res.* 47:D520–D528 (2019). doi:10.1093/nar/gky949

### Crystallography Open Database (A2)

CIFs, `allcod.smi`, and REST metadata.

- **License:** CC0. The database and all its data are dedicated to the public domain. See <https://www.crystallography.net/cod/>.
- **Requested:** acknowledgement of the original authors of the structural data (the COD id is in `meta_cod_id`).
- **Cite:**
  - Gražulis S et al. Crystallography Open Database (COD): an open-access collection of crystal structures and platform for world-wide collaboration. *Nucleic Acids Res.* 40:D420–D427 (2012). doi:10.1093/nar/gkr900
  - Quirós M et al. Using SMILES strings for the description of chemical connectivity in the Crystallography Open Database. *J. Cheminform.* 10 (2018). doi:10.1186/s13321-018-0279-6

### Merkys et al. 2023, Additional file 2 (A2)

The cross-check results used to select COD entries whose curated SMILES matches the coordinates.

- **License:** CC0 1.0 for the data, under the article's public-domain waiver. The article text is CC BY 4.0. See <https://doi.org/10.1186/s13321-023-00692-1>.
- **Cite:** Merkys A, Vaitkus A, Grybauskas A, Konovalovas A, Quirós M, Gražulis S. Graph isomorphism-based algorithm for cross-checking chemical and crystallographic descriptions. *J. Cheminform.* 15:25 (2023). doi:10.1186/s13321-023-00692-1

### QMugs (B1, C1)

- **License:** CC BY-SA 3.0 Unported. See the `LICENSE` and `REQUIRED_ATTRIBUTION` files at <https://libdrive.ethz.ch/index.php/s/X5vOBNSITAG5vzM> and doi:10.3929/ethz-b-000482129. The license of the *Sci. Data* article (CC BY 4.0) does not apply to the data.
- **Required:** attribution, and share-alike for adaptations.
- **Cite:**
  - Isert C, Atz K, Jiménez-Luna J, Schneider G. QMugs, quantum mechanical properties of drug-like molecules. *Sci. Data* 9:273 (2022). doi:10.1038/s41597-022-01390-7
  - Isert C, Atz K, Jiménez-Luna J, Schneider G. QMugs: Quantum Mechanical Properties of Drug-like Molecules. ETH Zurich (2021). doi:10.3929/ethz-b-000482129

### ChEMBL 27 (B1, C1)

`chembl_27_chemreps.txt.gz`, used to match QMugs graphs to ChEMBL compounds.

- **License:** CC BY-SA 3.0 Unported. See `LICENSE` and `REQUIRED.ATTRIBUTION` at <https://ftp.ebi.ac.uk/pub/databases/chembl/ChEMBLdb/releases/chembl_27/>.
- **Required:** attribution, and share-alike for adaptations. ChEMBL also asks that "the ChEMBL IDs are preserved, and that the release number of ChEMBL is clearly displayed". The release is **ChEMBL 27**, and the IDs are kept in `meta_chembl_id`.
- **Cite:** Mendez D et al. ChEMBL: towards direct deposition of bioassay data. *Nucleic Acids Res.* 47(D1):D930–D940 (2019). doi:10.1093/nar/gky1075

### GEOM, including GEOM-DRUGS and GEOM-QM9 (B1 exclusion list, B2, B3)

- **License:** CC0 1.0. See the Harvard Dataverse record at <https://doi.org/10.7910/DVN/JNGTDF>.
- **Cite:**
  - Axelrod S, Gómez-Bombarelli R. GEOM, energy-annotated molecular conformations for property prediction and molecular generation. *Sci. Data* 9:185 (2022). doi:10.1038/s41597-022-01288-4
  - GEOM-QM9 is derived from QM9, whose data is also CC0. Cite: Ramakrishnan R, Dral PO, Rupp M, von Lilienfeld OA. Quantum chemistry structures and properties of 134 kilo molecules. *Sci. Data* 1:140022 (2014). doi:10.1038/sdata.2014.22

For B1, GEOM is used only to exclude molecules that also appear in GEOM-DRUGS; no GEOM data is included in `B1.h5`.

### QCML (B3, C5)

- **License:** CC BY-NC 4.0, Copyright 2024 DeepMind Technologies Limited. See the Zenodo record at doi:10.5281/zenodo.14859804 and <https://creativecommons.org/licenses/by-nc/4.0/>.
- **Required:** attribution, an indication of changes, and no commercial use.
- **Changes made by bond-bench:** structures were selected and stratified, and bond-order labels were assigned and validated. QCML keys are kept in `meta_qcml_key`.
- **Cite:** Ganscha S, Unke OT, Ahlin D, Maennel H, Kashubin S, Müller K-R. The QCML dataset, Quantum chemistry reference data from 33.5M DFT and 14.7B semi-empirical calculations. *Sci. Data* 12:406 (2025). doi:10.1038/s41597-025-04720-7

- **Cite:** Grambow CA, Pattanaik L, Green WH. Reactants, products, and transition states of elementary chemical reactions based on quantum chemistry. *Sci. Data* 7:137 (2020). doi:10.1038/s41597-020-0460-4
